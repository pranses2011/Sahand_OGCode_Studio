## ⚡ معرفی

**Sahand GCode Studio** سه ماژول مستقل اما مرتبط دارد:

1. **ویرایشگر و تحلیل‌گر G-code** — بازکردن فایل محلی، متن کد و بازسازی سه‌بعدی مسیر نازل کنار هم، توضیح فارسی دقیق هر خط با پارامترها و وضعیت ماشین قبل/بعد، ویرایش زنده با به‌روزرسانی پیش‌نمایش، و «ذخیره با نام جدید» بدون بازنویسی فایل اصلی.
2. **طراح چاپ مارپیچی (vase-mode)** — ساخت فرم چرخشی از منحنی مقطع با گردش‌کار ۶ گامی (پروفایل → الگو → بافت → **دیواره (توری/سوراخ)** → کف (لامپ/آویز) → پرینتر)، پیش‌نمایش زنده و خروجی STL/G-code.
3. **متن به گلدان (vase-mode)** — هر متنی (فارسی/لاتین، هر فونت ویندوزی) به دیواره‌های مارپیچی بی‌درز تبدیل می‌شود با اتصال نامرئی حروف — ۱٫۷.

هیچ سرور، حساب کاربری، آپلود، CDN، telemetry یا auto-update وجود ندارد؛ همهٔ پردازش‌ها محلی روی سیستم شما انجام می‌شود.
تنها استثنا: **ارسال بازخورد/گزارش خطا** به ایمیل سازنده — ۱٫۷ به‌صورت **SMTP مستقیم** از سرور خودِ شما (تنظیمات محلی در «درباره ← تنظیمات ایمیل») انجام می‌شود؛ در نبود تنظیمات، سرویس فرم با دامنهٔ محدود `formsubmit.co` پشتیبان است (با صف محلی در نبود اینترنت). هیچ فایل یا دادهٔ دیگری ارسال نمی‌شود.

## 🆕 نسخهٔ ۱.۷.۰ — توری، سوراخ دیواره، لامپ/آویز حرفه‌ای، متن به گلدان، رفع ایمیل

| قابلیت | توضیح |
|---|---|
| **🕸️ چاپ توری (درخواست ۳)** | حالت دیوارهٔ **توری** با ۴ سبک خانه: **الماسی / مربعی / مهری / پیچان** — تارهای مورب با دورهٔ «n+½» طوری چاپ می‌شوند که انقلاب‌های مجاور در تقاطع‌ها جوش می‌کنند و خانه‌ها واقعاً باز می‌مانند (مثل مرجع). تنظیمات کامل: عرض/ارتفاع خانه، نسبت صعود، سرعت و جریان تارها، شروع/پایان ناحیهٔ توری (پایین دیواره جامد می‌ماند) |
| **🕳️ سوراخ واقعی دیواره (درخواست ۹)** | سوراخ‌ها «در خود دیواره» ساخته می‌شوند نه پوشش لایهٔ آخر: مارپیچ هنگام عبور از دهانه **travel** می‌کند (دهانهٔ باز)، خروج از سوراخ با travel تمیز (هیچ رشته‌ای از داخل شروع نمی‌شود) و دور هر سوراخ **قاب تقویتی بسته** چاپ می‌شود. ۵ شکل (دایره/مستطیل گردگوشه/لوزی/شش‌ضلعی/ستاره)، چینش آجری، ردیف×محیط، حاشیه‌ها، ۰..۳ پاس قاب |
| **🪝 آویز حرفه‌ای (درخواست ۷)** | ۴ سبک: سوراخ لبهٔ کف (نخ از زیر) / سوراخ بالای دیواره (زنجیر از بالا) / ترکیبی / هیچ — تعداد/قطر/موقعیت ٪شعاع/فاز سوراخ‌های کف، سوراخ‌های بالا با قاب، و **حلقه‌های تقویت لبهٔ بالا** (۱..۶ دور بسته در بالای فرم — لبهٔ تحت کشش ضخیم می‌شود) |
| **💡 لامپ حرفه‌ای (درخواست ۸)** | سوکت مرکزی با قطر استاندارد (دکمه‌های E14=۲۸ / E27=۴۰)، **حلقه‌های تقویت سوکت**، **پره‌های متصل‌کنندهٔ سوراخ به بدنه** با ۳ سبک (پهن موازی / تک‌خط / وب با کمان)، **کف نورپذیر** (ضریب فاصله) + حلقهٔ فرورفتهٔ سوکت + ۲ الگوی کف جدید: **وب لامپ** و **خورشیدشکاف** |

## 🆕 نسخهٔ ۱.۶.۰ — نمای جامد دقیق + اسپات زاویه‌ای + پایان‌بندی صحیح چاپ

| قابلیت | توضیح |
|---|---|
| **🗿 نمای جامد دقیق (رفع باگ مهم)** | مش «نوار مارپیچی» از **نقاط واقعی مسیر چاپ** ساخته می‌شود — الگو **و** بافت (شعاعی/عمودی) دقیقاً همان‌طور که چاپ می‌شوند دیده می‌شوند. قبلاً فقط پوش شعاعی حداکثری (سطح صاف) نمایش داده می‌شد. نورپردازی هم روشن‌تر شد: تُن ACES + نور پُرکننده (رفع «تیره است») |
| **🎯 اسپات زاویه‌ای الگو/بافت** | الگو/بافت به‌جای کل دور فرم، فقط روی یک **قوس زاویه‌ای** (مرکز + گسترهٔ قابل‌تنظیم) اعمال می‌شود. روی 3D: قوس طلایی + دو لبه با **فلش جهت‌دار** (کشیدن = پهن/باریک‌کردن) + دستهٔ سبز مرکز (کشیدن = چرخش قوس). لبه‌ها نرم (smoothstep) — برای چاپ خوب |
| **🏁 پایان‌بندی صحیح چاپ (رفع باگ مهم)** | پس از اتمام چاپ: رتراکشن → خاموشی هیتر بستر (M140 S0) و نازل (M104 S0) و فن (M107) → بالارفتن نسبی ۱mm (G91/G1 Z1/G90) → **هوم فقط X** (G28 X — Z بالا می‌ماند و پایین نمی‌آید) → M84. قبلاً G28 کامل صادر می‌شد که Z را تا میز پایین می‌آورد |
| **🎚️ کیفیت خروجی G-code** | دیالوگ ۴ سطح پیش از خروجی (ارسال به ویرایشگر یا ذخیرهٔ مستقیم): زبر (قوس ۴mm/اعشار ۲) / استاندارد (۲mm/۳) / ریز (۱mm) / بسیار ریز (۰٫۶۷mm/۴) با تخمین شمار خط. هدر فایل گزینهٔ کیفیت را ثبت می‌کند |

## 🆕 نسخهٔ ۱.۵.۰ — اسپلاین مماس‌دار + کتابخانهٔ پروفایل + نمای جامد

| قابلیت | توضیح |
|---|---|
| **🪢 اسپلاین پروفایل با فلش‌های مماس** | با انتخاب هر نقطه، دو فلش زرد «در دو سمت آن» ظاهر می‌شود؛ کشیدن فلش = تنظیم دقیق شیب مماس (m = dr/dh) و انحنای اسپلاین در همان نقطه — مثل اپ‌های ویرایش منحنی. دابل‌کلیک روی فلش = بازگشت به مماس خودکار. منحنی نمایش «همان ریاضی هستهٔ Rust» است (Fritsch–Carlson + هرمیت مکعبی) — چه می‌بینید همان چاپ می‌شود. سقف ۶δ فراجهش شدید را مهار می‌کند |
| **📚 کتابخانهٔ ۱۸ پروفایل آماده** | گلدان/سایه‌روشن/گلدان‌کشت + ۱۵ شکل جدید: لیوان، بطری، کاسه، ساعت شنی، جام، فانوس، آمفورا، قلم‌خانه، گلدان دوطبقه، تخم‌مرغی، بشکه، مخروط، شمع‌دان، دلو، سلادون — همه با thumbnail زنده و کاملاً قابل‌ویرایش |

| **📥 ایمپورت پروفایل از SVG** | پارسر کامل مسیر SVG (M/L/H/V/C/S/Q/T/A/Z آبشاری+مطلق، polyline/polygon/rect/circle/ellipse، transformهای translate/scale/matrix ساده) → نیم‌رخ راست کانتور → پروفایل (r,h) با مقیاس ارتفاع مقصد + ساده‌سازی Douglas–Peucker تطبیقی تا ≤۳۰ نقطه |
| **🎚️ دیالوگ کیفیت خروجی STL** | ۴ سطح: سریع (۰٫۵×) / استاندارد (۱×) / ریز (۲×) / بسیار ریز (۳×) با تخمین زندهٔ تعداد مثلث در هر کارت — کیفیت فقط ریزباشدِ سطح STL است؛ مسیر G-code و چاپ مستقل می‌مانند (آزمون‌شده) |

## 🆕 نسخهٔ ۱.۴.۰ — کف چندلایه + سرعت‌ها + G-code استاندارد + نمایشگر سریع

| قابلیت | توضیح |

| **🧱 کف چندلایه (رفع باگ مهم)** | در ۱.۳ کف به انتهای مسیر اضافه می‌شد و عملاً بعد از کل دیواره چاپ می‌شد. اکنون کف با تعداد لایهٔ قابل‌انتخاب (۱..۱۲) «قبل» از دیواره چاپ می‌شود و حالت مارپیچی (vase) از بالای کف ادامه می‌یابد — لایه‌های فرد الگوهای خطی ۹۰° چرخیده (cross-hatch) چاپ می‌شوند |

   | `G-code.Studio_full-setup.exe` (نصب کامل) | ~۲۰۰ MB | ویندوز **بدون اینترنت** — WebView2 داخل بسته است |
   | `G-code.Studio_light-setup.exe` (نصب آپدیت/سبک) | ~۱.۵ MB | **به‌روزرسانی سریع** — WebView2 فقط اگر نصب نباشد آنلاین دانلود می‌شود (ویندوز ۱۰/۱۱ به‌روز تقریباً همیشه دارد) |

   💡 برای آپدیت نسخهٔ قبلی، همان فایل سبک را نصب کنید — روی نسخهٔ موجود نصب می‌شود.
3. فایل را اجرا کنید؛ نصب per-user است و به admin نیاز ندارد.

اگر رلیسی موجود نیست (مثلاً پیش از اولین تگ): تب **Actions** → workflow **windows-build** → آخرین اجرای موفق → artefact **`gcode-studio-windows-x64`** (شامل هر دو نصب‌کننده).

### مشخصات نصب

- **هدف:** Windows 10 22H2 / Windows 11 x64
- **نصب per-user** (بدون نیاز به admin)
- **نصب کامل:** WebView2 با حالت `offlineInstaller` داخل بسته — نصب روی سیستم بدون اینترنت ممکن است.
- **نصب سبک:** حالت `downloadBootstrapper` — تنها در صورت نبود WebView2 (که در اکثر ویندوزهای به‌روز هست) نیاز به اینترنت لحظه‌ای هنگام نصب دارد؛ خود برنامه همچنان کاملاً آفلاین است.
- گزینهٔ `fixedRuntime` عمداً به‌کار نرفته: حجم نصب‌کننده را چند ده مگابایت بزرگ می‌کند و به‌روزرسانی امنیتی WebView2 را از کنترل کاربر خارج می‌کند. اگر این trade-off برایتان مهم است، در `src-tauri/tauri.conf.json` قابل تغییر است.
- حذف برنامه (uninstall) فایل‌های G-code و پروژه‌های شما را پاک **نمی‌کند**.

### build از سورس

```bash
# پیش‌نیاز: Node 20+ و Rust stable
npm install
npm test              # آزمون‌های فرانت‌اند (Vitest)
cd src-tauri
cargo test -p gcode-core   # ۱۶۳ آزمون هستهٔ Rust
cd ..
npm run tauri build   # نصب کامل (آفلاین) — src-tauri/target/release/bundle/nsis/
npm run tauri build -- --config src-tauri/tauri.light.conf.json   # نصب سبک (آپدیت)
```

> **محدودیت صادقانهٔ محیط:** این ریپو روی سرور Linux توسعه یافته است؛ build پوستهٔ Tauri (که به WebView2/GTK وابسته است) روی Windows انجام می‌شود — CI گیت‌هاب همین کار را می‌کند و روی تگ‌های `v*` رلیس با فایل نصب می‌سازد. **تست نصب آفلاین روی ویندوز واقعی با اینترنت قطع، در محیط توسعه انجام نشده و «اجرا‌نشده» گزارش می‌شود.**

## 🛠️ توسعه در مرورگر (پل هستهٔ Rust)

برای توسعهٔ رابط کاربری بدون پوستهٔ دسکتاپ، `npm run dev` سرو می‌کند و دستورهای محاسباتی (تفسیر/طراح/پریست‌ها) از طریق پل توسعه به **باینری `gcode-cli`** (همان هستهٔ Rust، بدون هیچ دادهٔ ساختگی) وصل می‌شوند:

```bash
cargo build -p gcode-cli   # یک‌بار در src-tauri
npm run dev                # http://localhost:1420
```

دیالوگ‌های فایل native و Save As فقط در پوستهٔ دسکتاپ کار می‌کنند (خطای صادقانه می‌گیرید، نه رفتار جعلی).

## 🔒 امنیت و حریم خصوصی

- ۱۸ دستور IPC دامنه‌ای؛ **هیچ shell/eval وجود ندارد**.
- دسترسی فایل فقط از دیالوگ native (capability: `core:default` + `dialog:default`).
- تنها شبکهٔ مجاز: `https://formsubmit.co/*` (بازخورد/گزارش خطا — ۱٫۶) در scope پلاگین HTTP و CSP؛ بقیهٔ remote sourceها مسدود.
- بدون telemetry/log محتوا؛ تنظیمات و پروفایل‌های شخصی فقط در AppData.
- متن گزارش خطا پیش از ارسال پاک‌سازی می‌شود (مسیر فایل‌های محلی و توکن‌ها حذف می‌شوند).
