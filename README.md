## ⚡ معرفی

**G-code Studio** دو ماژول مستقل اما مرتبط دارد:

1. **ویرایشگر و تحلیل‌گر G-code** — بازکردن فایل محلی، متن کد و بازسازی سه‌بعدی مسیر نازل کنار هم، توضیح فارسی دقیق هر خط با پارامترها و وضعیت ماشین قبل/بعد، ویرایش زنده با به‌روزرسانی پیش‌نمایش، و «ذخیره با نام جدید» بدون بازنویسی فایل اصلی.
2. **طراح چاپ مارپیچی (vase-mode)** — ساخت فرم چرخشی از منحنی مقطع با گردش‌کار ۵ گامی (پروفایل → الگوی هندسی → بافت مسیر → کف → تنظیمات پرینتر)، پیش‌نمایش زنده و خروجی STL/G-code.

هیچ سرور، حساب کاربری، آپلود، CDN، telemetry یا auto-update وجود ندارد؛ همهٔ پردازش‌ها محلی روی سیستم شما انجام می‌شود.

## 🆕 نسخهٔ ۱.۴.۰ — کف چندلایه + سرعت‌ها + G-code استاندارد + نمایشگر سریع

| قابلیت | توضیح |
|---|---|
| **🧱 کف چندلایه (رفع باگ مهم)** | در ۱.۳ کف به انتهای مسیر اضافه می‌شد و عملاً بعد از کل دیواره چاپ می‌شد. اکنون کف با تعداد لایهٔ قابل‌انتخاب (۱..۱۲) «قبل» از دیواره چاپ می‌شود و حالت مارپیچی (vase) از بالای کف ادامه می‌یابد — لایه‌های فرد الگوهای خطی ۹۰° چرخیده (cross-hatch) چاپ می‌شوند |
| **⚡ سرعت‌ها (mm/s)** | سرعت لایهٔ اول (پیش‌فرض ۵۰٪)، لایه‌های بعدی کف (۷۵٪)، دیوارهٔ مارپیچ و جابجایی — در UI به mm/s، در G-code به F استاندارد (mm/min). رتراکشن (طول/سرعت) هم قابل‌تنظیم است |
| **📄 G-code خروجی استاندارد** | travelها G0 بدون E (قبلاً G1 با E صفر!)، F فقط هنگام تغییر سرعت، ;LAYER:n و ;TYPE:FLOOR/WALL-OUTER برای viewerها، G28 خودکار اگر start کد نداشته باشد + G92 E0، رتراکشن/آنرتراکشن استاندارد دور جابجایی‌های بلند کف، فقط محورهای تغییرکرده در هر خط (axis modality اسلایسرها) |
| **🚀 نمایشگر سه‌بعدی سریع** | رندر به‌اقتضا (فقط هنگام تغییر/تعامل، نه ۶۰fps دائم)، پیلود تخت IPC به‌جای JSON شیءمحور چند‌MB، رفع پرش دوربین در هر تغییر اسلایدر، بازاستفادهٔ بافرها و سقف DPR=۲ |
| **🎯 اسپات روی سطح مدل** | دستهٔ نارنجی/آبی الگو/بافت «روی فرم» در زاویهٔ فاز: درگ عمودی = جابه‌جایی ارتفاع، درگ افقی = چرخش زاویهٔ فاز خود الگو (جدا از دیال فاز کل فرم) — تجربهٔ دست‌کاری مستقیم مثل ابزارهای طراحی سه‌بعدی |
| **🔗 سازگاری کامل** | پروژه‌های قدیمی بدون فیلدهای جدید با پیش‌فرض‌های ۱.۴ باز می‌شوند (کف ۲ لایه؛ mm/s=۰ یعنی پیروی از mm/min قدیمی) — هیچ داده‌ای از دست نمی‌رود |

## 🆕 نسخهٔ ۱.۳.۰ — چرخش فاز θ + دما + نصب آپدیت سبک

| قابلیت | توضیح |
|---|---|
| **🔄 اسپات چرخش فاز θ** | دیال بنفش روی نمای سه‌بعدی: نشانگر را حول محور بکشید تا زاویهٔ شروع مارپیچ (جای درز seam) و جهت‌گیری گلبرگ/شیارها بچرخد — mesh و مسیر و کف هم‌زاویه می‌مانند. Shift = چفت ۱۵°؛ فیلد عددی هم هست |
| **🌡️ تنظیم دمای نازل و میز کار** | به‌همراه فن خنک‌کننده و گزینهٔ انتظار — خروجی استاندارد M140/M104 (تنظیم) و M190/M109 (انتظار) + M106/M107 (فن). دمای ۰ یعنی «فرمان دما ننویس» (کنترل دستی) |
| **🧪 پریست مواد** | ۵ دکمه: PLA (200/60)، PETG (240/80)، ABS (250/100)، TPU (225/45)، PLA ابریشمی (215/65) — فن هم مطابق ماده تنظیم می‌شود؛ «شروع مناسب رایج» نه عدد قطعی |
| **📦 نصب آپدیت سبک** | هر رلیس دو فایل دارد: نصب کامل آفلاین (~۲۰۰MB با WebView2 داخل بسته) + **نصب آپدیت/سبک (~۱.۵MB)** که WebView2 را فقط در صورت نبود دانلود می‌کند — برای به‌روزرسانی سریع به‌جای دانلود ۲۰۰MB |
| **خلاصهٔ هوشمند** | خلاصهٔ خروجی حالا فاز θ و دمای نازل/بستر را هم نشان می‌دهد؛ هدر G-code هم phase_start/temp/fan را برای بازرسی می‌نویسد |
| **سازگاری کامل** | پروژه‌های ۱.۱/۱.۲ بدون فاز و دما ذخیره شده‌اند و با پیش‌فرض‌های ۱.۳ (فاز ۰، PLA 200/60) باز می‌شوند — هیچ داده‌ای از دست نمی‌رود |

## 🎨 رنگ‌ها و الگوها

**۱۷ الگوی هندسی** (هندسهٔ مدل را تغییر می‌دهند → در STL می‌مانند):

| الگو | توضیح |
|---|---|
| موج محوری | برجستگی سینوسی دور محور، با فرکانس عمودی |
| گلبرگ (چندلوبی) | k گلبرگ با فرم cos² |
| پیچش | موجی که با ارتفاع می‌چرخد (توهم تاب) |
| شیار عمودی | کانال‌های عمودی مثل ستون کلاسیک |
| لوزی | شبکهٔ لوزی از برجستگی‌ها (زاویه × ارتفاع) |
| مهری (زیگزاگ) | موج مثلثی مورب — چین‌مانند |
| حلقهٔ افقی | برجستگی‌های حلقه‌ای مستقل از زاویه (دیوارهٔ داسی) |
| فلس | ردیف‌های مورب فلس‌های هم‌پوشان (زره‌مانند) |
| تراش‌خورده | مقطع k-ضلعی منتظم با عمق کنترل‌شونده و چرخش اختیاری با ارتفاع |
| **رشته‌ای (طناب)** 🆕 | تار و پود درهم‌بافته — sin(kθ+t)·cos(kθ−t) |
| **آناناسی** 🆕 | شبکهٔ لوزی تیز با سلول‌های برجستهٔ کج (جذر |sin|) |
| **نیلوفر (آبشاری)** 🆕 | ردیف‌های گلبرگ هم‌پوشان با جابه‌جایی نصف‌گلبرگ در هر ردیف |
| **شیار پیچان** 🆕 | شیارهایی که با ارتفاع می‌پیچند (ستون باروک) |
| **مروارید** 🆕 | دانه‌های گرد cos⁴ با جابه‌جایی نصف‌دور در هر ردیف |
| **یونانی** 🆕 | بلوک‌های مربعی متناوب — نقش های‌یونانی |
| **آجری** 🆕 | ردیف‌های ذوزنقه‌ای نیم‌جابه‌جا مثل دیوار آجری |
| **خاردار** 🆕 | خارهای مثلثی تیز با جابه‌جایی ارتفاعی |

**۱۲ بافت مسیر** (مسیر نازل را تعدیل می‌کنند → فقط در G-code):

موجک (ریپل) • تور بافته • بخیه‌ای • شیار مارپیچی • چکشی (قطعی و بدون RNG) • سبدی • **رگهٔ چوب** 🆕 • **چرم** 🆕 • **آج رزوه** 🆕 • **موج دریا** 🆕 • **حباب** 🆕 • **تخته‌ای** 🆕

**۵ الگوی کف** 🆕 (گام ۴ — همه مسیر واقعی تولید می‌کنند):

حلقه‌های هم‌مرکز • مارپیچ پیوسته (یک مسیر بدون travel — مناسب vase) • شبکهٔ متقاطع • پرتوهای شعاعی (تعداد قابل‌تنظیم) • رفت‌وبرگشتی (بدون درز)

**۸ تم رنگی** (نارنجی صنعتی، سایان، سبز، بنفش، کهربایی، سرخابی، آبی، قرمز) + **۱۰ رنگ رشتهٔ چاپ** برای پیش‌نمایش سه‌بعدی — با ماندگاری محلی (بدون ذخیرهٔ راه‌دور).

## 📦 نصب

### دانلود از رلیس (ساده‌ترین راه)

1. به بخش **[Releases](https://github.com/pranses2011/Sahand_OGCode_Studio/releases)** ریپازیتوری بروید.
2. در آخرین رلیس (مثلاً `v1.3.0`) **یکی از دو فایل** را دانلود کنید:

   | فایل | حجم تقریبی | مناسب چه کسی؟ |
   |---|---|---|
   | `G-code.Studio_full-setup.exe` (نصب کامل) | ~۲۰۰ MB | ویندوز **بدون اینترنت** — WebView2 داخل بسته است |
   | `G-code.Studio_light-setup.exe` (نصب آپدیت/سبک) | ~۱.۵ MB | **به‌روزرسانی سریع** — WebView2 فقط اگر نصب نباشد آنلاین دانلود می‌شود (ویندوز ۱۰/۱۱ به‌روز تقریباً همیشه دارد) |

   💡 برای آپدیت نسخهٔ قبلی، همان فایل سبک را نصب کنید — روی نسخهٔ موجود نصب می‌شود.
3. فایل را اجرا کنید؛ نصب per-user است و به admin نیاز ندارد.

اگر رلیسی موجود نیست (مثلاً پیش از اولین تگ): تب **Actions** → workflow **windows-build** → آخرین اجرای موفق → artefact **`gcode-studio-windows-x64`** (شامل هر دو نصب‌کننده).

### مشخصات نصب

- **هدف:** Windows 10 22H2 / Windows 11 x64
- **نصب per-user** (بدون نیاز به admin)
- **نصب کامل:** WebView2 با حالت `offlineInstaller` داخل بسته — نصب روی سیستم بدون اینترنت ممکن است.
- **نصب سبک:** حالت `downloadBootstrapper` — تنها در صورت نبود WebView2 (که در اکثر ویندوزهای به‌روز هست) نیاز به اینترنت لحظه‌ای هنگام نصب دارد؛ خود برنامه همچنان کاملاً آفلاین است.
- گزینهٔ `fixedRuntime` عمداً به‌کار نرفته: حجم نصب‌کننده را چند ده مگابایت بزرگ می‌کند و به‌روزرسانی امنیتی WebView2 را از کنترل کاربر خارج می‌کند. اگر این trade-off برایتان مهم است، در `src-tauri/tauri.conf.json` قابل تغییر است.
- حذف برنامه (uninstall) فایل‌های G-code و پروژه‌های شما را پاک **نمی‌کند**.

### build از سورس

```bash
# پیش‌نیاز: Node 20+ و Rust stable
npm install
npm test              # آزمون‌های فرانت‌اند (Vitest)
cd src-tauri
cargo test -p gcode-core   # ۱۶۳ آزمون هستهٔ Rust
cd ..
npm run tauri build   # نصب کامل (آفلاین) — src-tauri/target/release/bundle/nsis/
npm run tauri build -- --config src-tauri/tauri.light.conf.json   # نصب سبک (آپدیت)
```

> **محدودیت صادقانهٔ محیط:** این ریپو روی سرور Linux توسعه یافته است؛ build پوستهٔ Tauri (که به WebView2/GTK وابسته است) روی Windows انجام می‌شود — CI گیت‌هاب همین کار را می‌کند و روی تگ‌های `v*` رلیس با فایل نصب می‌سازد. **تست نصب آفلاین روی ویندوز واقعی با اینترنت قطع، در محیط توسعه انجام نشده و «اجرا‌نشده» گزارش می‌شود.**

## 🛠️ توسعه در مرورگر (پل هستهٔ Rust)

برای توسعهٔ رابط کاربری بدون پوستهٔ دسکتاپ، `npm run dev` سرو می‌کند و دستورهای محاسباتی (تفسیر/طراح/پریست‌ها) از طریق پل توسعه به **باینری `gcode-cli`** (همان هستهٔ Rust، بدون هیچ دادهٔ ساختگی) وصل می‌شوند:

```bash
cargo build -p gcode-cli   # یک‌بار در src-tauri
npm run dev                # http://localhost:1420
```

دیالوگ‌های فایل native و Save As فقط در پوستهٔ دسکتاپ کار می‌کنند (خطای صادقانه می‌گیرید، نه رفتار جعلی).

## 🔒 امنیت و حریم خصوصی

- فقط ۱۳ دستور IPC دامنه‌ای؛ **هیچ shell/eval/شبکه‌ای وجود ندارد**.
- دسترسی فایل فقط از دیالوگ native (capability فقط `core:default` + `dialog:default`).
- CSP بدون هیچ remote source؛ همهٔ assetها داخل باندل.
- بدون telemetry/log محتوا؛ تنظیمات فقط در AppData.
